## 核心设计定位提示

- **观察目标**：中文工程回答的六类可观测文风病灶（首句太极推延、防御性免责叠甲、报菜名与电报压缩、正文外显推演与分号长链、悬空裸代号与欧化官腔、跨语域表格墙与套话抽动）。
- **因果边界**：“后训练过对齐（SFT / RLHF / DPO / CoT）”是解释上述表达习性的待验证机制假设。在缺乏同基座前/后训练严格对照的条件下，本榜单只陈述当前路由与调用配置下的可观测语言风格差异。
- **评测约束**：只评表达方式、不判答案对错，采用 `markdown-it-py` AST 与 `jieba` 词法确定性打分，零裁判模型，0 分代表未检出六类惩罚模式（不代表知识正确或回答完整）。辅以 1000 次 Bootstrap 95% 置信区间与奇偶分半信度控制小样本方差。
