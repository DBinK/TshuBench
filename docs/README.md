## 核心设计定位提示

- **目标问题**：量化大语言模型（LLM）**后训练过对齐（Post-training Over-alignment）**引发的六大语言表达与排版病灶（首句太极推延、防御性免责叠甲、报菜名与电报压缩、正文外显推演与分号长链、悬空裸代号与欧化官腔、跨语域表格墙与套话抽动）。
- **人机边界**：“模型不说人话”是人类读者感知到的主观体感，其深层技术成因是后训练过程中的过对齐、CoT 蒸馏外溢与长度/排版奖励偏见。
- **评测约束**：只评表达方式、不判答案对错，采用 `markdown-it-py` AST 与 `jieba` 词法确定性打分，零 LLM-as-a-Judge 裁判模型，辅以 95% Bootstrap 置信区间与梯队划分抑制 24 题校准集小样本噪声。
