## 核心设计定位提示

- **目标问题**：量化大语言模型（LLM）**后训练过对齐（Post-training Over-alignment）**引发的语言退化特征（防御性叠甲、报菜名堆砌、社交骑墙奉承）。
- **人机边界**：“模型不说人话”是人类读者感知到的主观体感，其深层技术成因是后训练过程中的过对齐与长度/排版奖励偏见。
- **评测约束**：只评表达方式、不判答案对错；100% 纯 Python 标准库确定性打分；零 LLM-as-a-Judge 裁判模型；95% Bootstrap 置信区间防组内噪声。
