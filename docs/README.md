## 核心设计定位

- **评测对象**：面向中文研发协作场景，量化六类可观测的表达负担（首句推延、免责叠甲、报菜名堆砌、推演外溢与长句嵌套、排版膨胀、套话模板）。
- **因果边界**：“后训练过对齐（SFT / RLHF / DPO / CoT 蒸馏）”是解释表达习性的一种待验证机制假设。当前基准只对确定性上下文中的实际文本做可复现风格测量，不越界下因果定论。
- **计算约束**：只评表达方式、不判技术对错，零裁判模型，确定性 AST 与词法分析，辅以 1000 次 Bootstrap 抽样估计 95% 置信区间。
