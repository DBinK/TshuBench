# 题库来源候选

> 状态：独立盲测集候选源仍**未接入**，仅留档。当前 `tasks/eval_suite_v2.jsonl`（36 题）均提炼自作者本机日常真实工程提问并经统一脱敏整理，无外部公开语料来源。
> 核查日期：2026-11-15

## 一、为什么需要这份清单

当前 36 题日常工程开发校准集围绕开发者的实际工作场景编写与审校，虽已具备良好的奇偶分半信度（总分 $r_{SB} = 0.917$），但在扩建至 120 题**独立盲测集（Held-out Test Split）**时，仍需引入未参与规则调试的真实外部开发者提问与独立人工评分，用来检验算子的泛化效度并排除研发集过拟合风险。

接入外部题源前必须先解决三件事：许可证、数据污染、个人信息。

## 二、候选来源

| 来源 | 许可证 | 内容形态 | 适配度 | 主要风险 |
| --- | --- | --- | --- | --- |
| Stack Exchange | CC BY-SA 4.0 | 真实开发者问答 | 中。题形接近，中文量少 | 署名加相同方式共享，2024 年起官方限制 dump 用于 AI 训练 |
| SWE-bench | MIT | 英文 issue 与修复 | 中。真实，但单轮修 bug，不是决策题 | 英文，需译写，需查污染 |
| LCCC / CDial-GPT | MIT | 人与人中文对白 | 中。可抽真实提问，偏闲聊 | 场景与工程协作距离远 |
| GitHub issue（Apache-2.0 项目） | 仓库许可证只管代码 | 中文技术讨论 | 高。场景最接近排障与同步 | issue 评论区许可证不明确，需法务确认 |
| C-Eval / MMLU / GAOKAO-Bench | 待核实 | 知识选择题 | 低 | 有唯一答案、无表达开放度，测不出 CVD、HED、ENU |
| WildChat / LMSYS-Chat-1M | 待核实 | 真实用户与模型对话 | 待评估 | 仓库路径未能核实，含个人信息与毒性内容 |

已核实项：SWE-bench 与 CDial-GPT 的仓库许可证经 GitHub API 读取为 MIT。Stack Exchange 的用户内容为 CC BY-SA 4.0，2024 年起官方对 dump 增加登录与禁止训练 AI 的限制，与 CC 协议存在冲突。

## 三、接入原则

1. **只复用题干，不复用对方的评分与题目结构**。知识选择题、单选题一律不改写使用。
2. **自然问法优先，严禁人工塞入字数指令**。题目须在常规工程对话里自然构成三类结构之一：明确边界（`explicit_bound`）、伪前提陷阱（`flawed_premise`）、强制选择（`forced_choice`）。
3. **全部题目仍需逐题标注锚点**。不要求标准答案，但必须标注 `verdict_anchors`、`actionable_entities`、`fence_sitting_markers` 与 `max_chars`。
4. **分层配比**：本机工程提问改写 40%，外部开源提问改写 30%，对抗同义变体与规则反例检查集 30%。
