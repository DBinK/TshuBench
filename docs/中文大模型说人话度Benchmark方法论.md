## 1. 项目定位与核心哲学

### 1.1 什么是中文「AI 味」（Chinese AI Slop）
在大语言模型（LLM）的中文生成中，「不说人话」（Slop / AI 味）特指一种**病态的文本风格**：
> **在语法完全合规、标点规范、逻辑通顺无硬伤的前提下，充斥着极低的信息密度、机械均匀的句长节奏、模式化的二元对比、泛滥的客服式虚伪热情、高频堆砌的四字成语与空洞拔高的价值升华。**

这种风格让读者能够在 3 秒内识别出“机器味”，产生严重的阅读疲劳与信息折损。它不属于事实性幻觉（Hallucination），也不属于安全违规（Safety/Toxicity），而是大模型在预训练与 RLHF/SFT 对齐过程中形成的**语言审美退化与交流钝化**。

### 1.2 现有 Benchmark 的盲区与本基准定位
当前主流中文基准（如 C-Eval、CMMLU、SuperCLUE 等）集中在知识考试与逻辑推理能力；风格类评测（如 AlpacaEval、Chatbot Arena、HeartBench）则存在以下核心局限：
1. **重英文轻中文**：SlopBench、The Slop Index 针对英文词频、单词数、拉丁字母标点开发，无法迁移至无空格分词、重意合、高频省略主语的中文语境。
2. **重主观裁判轻机械指标**：普遍依赖 LLM-as-a-Judge 给主观分，受到严重的**长度偏见（Length Bias）、位置偏见（Position Bias）与自好偏见（Self-Preference Bias）**干扰，导致“写得越长、排版越花哨，裁判给分越高”，形成了反向劣币驱逐良币。
3. **缺少真实人类历史基准**：缺乏与大模型诞生前（Pre-ChatGPT，2022 年 11 月前）真实人类自然文本的对比校准。

**本基准（Chinese SlopBench / 说人话 Index）定位**：
**全球首个面向中文大语言模型的「说人话度」可量化、可复现、带人类基线锚定的综合评测体系。** 目标是回答：**“在完成相同交流目标时，哪家大模型写得最像一个干练、真诚、自然的现代中国人，哪家模型写得最僵化、最套话连篇？”**

### 1.3 核心设计原则
1. **客观物理特征优先（Mechanical First, 60%）**：无随机性、本地单机秒级计算、代码全开源，杜绝黑盒裁判模型的偏见。
2. **真实人类对战校准（Human Arena Calibration, 40%）**：采用匿名众包双盲成对投票（Pairwise Elo），以真实读者的生理审美为终极仲裁。
3. **双侧偏离度惩罚（Two-Sided Deviation Penalty）**：**人话不是极简主义，也不是通篇粗鄙俚语。** 优秀的人类写作存在一个合理的自然分布带。过度书面化（0 语气词）与对抗性装口语（通篇“哈/呀”）同等扣分。
4. **语域感知与误杀豁免（Register-Aware & Guardrailed）**：严格区分技术文档、严肃汇报、日常闲聊与公开发表，对真实技术术语、合理排版设置白名单，绝不搞“因词废文”。

## 2. 评测维度体系（Five Core Dimensions）

### 2.1 整体分值架构（60/40 混合模型）
总榜单发布两项对偶分值（取值均为 $[0, 100]$）：

$$\text{Slop Index (AI 味指数)} = 0.60 \times S_{\text{mechanical}} + 0.40 \times S_{\text{human}}$$

$$\text{Humanity Index (说人话指数)} = 100 - \text{Slop Index}$$

- **0 分 Slop Index**：代表文本特征与 Pre-ChatGPT 人类基线在统计学上无法区分，且在人类双盲盲测中胜率与人类相当。
- **100 分 Slop Index**：代表极端典型的 AI 废话发生器。

### 2.2 五大机械维度与权重分配

机械分 $S_{\text{mechanical}}$ 由以下五个正交维度加权合成（各维度内部已做归一化）：

| 维度编号 | 维度名称 | 英文标识 | 核心考量 | 机械分权重 $w_k$ |
| :--- | :--- | :--- | :--- | :--- |
| **DIM-C** | **篇幅膨胀度** | Conciseness Inflation | 是否超出 Prompt 规定的字数带上限；是否存在纯粹为了充字数的空泛铺垫与复述 | **25%** |
| **DIM-T** | **模板僵化度** | Structural Templating | 跨样本开场白雷同率；是否僵化套用“总-分-总”、“首先/其次/最后”八股结构 | **25%** |
| **DIM-R** | **韵律机械度** | Rhythm Monotony | 句长变异系数（是否机械均匀）；四字成语与虚假排比的滥用程度 | **15%** |
| **DIM-K** | **套话标记度** | Slop Tells & Hallmarks | 命中 AI 标志性特征词汇与反模式（二元对比、互联网黑话、工程师表演腔、虚假升华） | **20%** |
| **DIM-O** | **口语活性缺失度** | Orality Deficiency | 中文特有语气助词、主语合理省略、轻动词化现象与人类基线分布的偏离程度 | **15%** |

## 3. 中文特有病灶指标与检测算法（Chinese-Specific Metrics & Formulations）

针对中文语言学特质与本土 AI 模型的训练污染特征，本基准建立了一套系统化的病灶指标库。所有指标均具备**明确的数学定义、正则表达与上下文白名单过滤规则**。

### 3.1 词汇与句内标记层（Lexical & Phrasal Level）

#### 指标 3.1.1：轻动词泛滥率（Light Verb Ratio, $M_{\text{light\_verb}}$）
- **语言学机制**：受英语“make/conduct/perform + nominalization”翻译腔侵蚀，大模型极度偏好用虚化动词（轻动词）搭配动作名词，破坏汉语“动词直截了当”的表达优势。
- **典型表现**：“进行深入分析” $\to$ “分析”；“作出合理调整” $\to$ “调整”；“予以高度关注” $\to$ “关注”。
- **计算公式**：
  $$M_{\text{light\_verb}} = \frac{\sum \text{Match}(P_{\text{light}})}{N_{\text{sentences}}}$$
  其中正则模式 $P_{\text{light}}$ 定义为：
  `(?<![不未无])(?:进行|作出|实施|予以|展开|开展)(?:了|过)?(?:一个|一些|更加|更为|充分的|全面的)?(?:\w{2,4})(?:分析|调整|优化|测试|讨论|梳理|评估|排查|总结|重构)`

#### 指标 3.1.2：机械二元对比密度（False Binary Antithesis, $M_{\text{binary}}$）
- **语言学机制**：AI 极度热衷通过制造虚假戏剧张力与假性深度来抬高论述价值，最典型的就是对毫无必要的事物使用“不是X，而是Y”或“不仅是X，更是Y”。
- **典型表现**：“这不仅是一个导出按钮，更是通往高效协作的全新入口。”
- **计算公式**：
  $$M_{\text{binary}} = \frac{\text{Count}(P_{\text{binary}}) - \text{Count}(\text{WhiteList}_{\text{factual}})}{N_{\text{sentences}}}$$
  其中正则模式 $P_{\text{binary}}$ 为：
  `(?:不仅(?:仅)?(?:是|能|代表).*?更(?:是|能|代表)|不是.*?而是|与其说是.*?不如说是)`
- **白名单规则（必须放行）**：若对比项存在明确的技术排他事实（例如：“错误发生在保存阶段，而不是上传阶段”；“这不是硬件故障，而是网络超时”），由语法依存树或事实对比词库放行。

#### 指标 3.1.3：四字成语与四字骈句密度（Four-Character Chunking, $M_{\text{four\_char}}$）
- **语言学机制**：大模型中文语料中充斥着政经报告、公文与高考作文，导致模型产生强烈的“四字格强迫症”，动辄连续罗列 2-4 个四字词进行虚假赋能。
- **典型表现**：“深耕细作、笃行致远、守正创新、久久为功”。
- **计算公式**：
  $$M_{\text{four\_char}} = \frac{\sum_{k \ge 2} k \times \text{Count}(\text{ConsecutiveFourChars}_k)}{N_{\text{chars}} / 100}$$
  连续出现的四字结构赋予平方级权重惩罚。

#### 指标 3.1.4：客服谄媚与情绪填料密度（Sycophancy & Filler, $M_{\text{sycophancy}}$）
- **典型表现**：“好问题！”、“很高兴为您解答！”、“您的想法非常深刻！”、“希望以上方案能为您带来启发！”。
- **判定规则**：在非客服（Customer Service）明确设定的任务中，若开场或结尾出现纯情绪填充句，计入病灶数。

#### 指标 3.1.5：新旧黑话污染指数（Jargon Pollution Index, $M_{\text{jargon}}$）
分为两个世代的特征词典：
- **Generation-1（互联网大厂黑话）**：`赋能|闭环|抓手|颗粒度|对齐|拉通|沉淀|心智|组合拳|打法|生命周期|全场景`。
- **Generation-2（工程师表演腔 / 职场伪深沉）**：在日常非技术对话或轻量沟通中生搬硬套：`兜底|压实|收敛|收束|链路|心智模型|击穿|穿透|底层逻辑|顶层设计`。
- **公式**：按每千字命中黑话词库的有效频次计算。**严格技术场景下启动术语白名单。**

### 3.2 句式与结构层（Syntactic & Structural Level）

#### 指标 3.2.1：首句开场白套路重复率（Modal Opener Share, $M_{\text{opener}}$）
- **定义**：对同一个任务 prompt，模型进行 $K=5$ 次独立采样。提取每个输出去除 Markdown 标记和空格后的**前 10 个汉字字符** $O_1, O_2, \dots, O_K$。
- **公式**：
  $$M_{\text{opener}} = \frac{\max_{v} \text{Freq}(O_i == v)}{K}$$
- **判定**：若 5 次输出中有 4 次均以“当然可以，关于您提到的”或“在当今快节奏的工作中”开头，则该题首句套路率为 80%。真实人类在多次被问及同一问题时，开场词汇丰富多变，众数占比通常 $< 40\%$。

#### 指标 3.2.2：八股连接词与骨架密度（Rigid Transitions, $M_{\text{transitions}}$）
- **表现**：段落或列表机械化依赖“首先、其次、再者、最后”、“一方面、另一方面”、“综上所述”、“总而言之”。
- **计算**：统计上述路标连接词在全文分句中的占比。若一篇 300 字短文命中超过 4 处八股连接词，记高病灶分。

#### 指标 3.2.3：无增量升华收尾（Vacuous Elevation Ending, $M_{\text{elevation}}$）
- **定义**：检测输出的最后一段或最后一句是否以「总之/总而言之/让我们/未来」引导，且该分句**未引入任何新参数、新动作或排期条件**，纯粹进行价值拔高或祝愿（例如：“让我们一起拥抱效率的变革，开启美好明天！”）。
- **判定算法**：正则匹配收尾引导词 + 实体/动词增量检测。若增量实体数为 0，则该项判定为 1（命中），否则为 0。

#### 指标 3.2.4：伪对比「与其...不如...」与虚构假想敌（Strawman Arguing, $M_{\text{strawman}}$）
- **表现**：“或许有人会认为...但事实上...”、“不用担心，我并不是要制造焦虑...”。AI 极喜欢在没有反方的情况下自我辩解。

### 3.3 韵律与信息密度层（Rhythm & Density Level）

#### 指标 3.3.1：句长变异系数（Sentence Length CV, $M_{\text{sent\_cv}}$）
- **语言学机制**：优秀的人类中文作者在叙事与论述时，具有自然的呼吸感与韵律节拍——短句断定（3–8字），长句陈述（20–40字）。而大模型生成的句子长度呈现出极度集中的正态分布（机械均匀）。
- **计算公式**：
  将文本按中文句末标点（`。！？\n；`）拆分为句子集合，过滤代码块与列表，得到每句字数序列 $L = [l_1, l_2, \dots, l_n]$。
  $$\mu_L = \frac{1}{n} \sum_{i=1}^n l_i, \quad \sigma_L = \sqrt{\frac{1}{n} \sum_{i=1}^n (l_i - \mu_L)^2}$$
  $$CV_L = \frac{\sigma_L}{\mu_L}$$
- **基线参考**：Pre-ChatGPT 真实人类文本的 $CV_L$ 中位数为 $0.78$（长短错落）；大模型常见 $CV_L$ 在 $0.30 - 0.45$ 之间。该指标采用双侧偏离惩罚。

#### 指标 3.3.2：长定语堆叠与「的」字密集度（Genitive Clutter, $M_{\text{de\_density}}$）
- **表现**：中文天然倾向于短修饰语或后置说明，AI 翻译腔则产生多重定语嵌套，导致「的」字密集出现。
- **公式**：
  $$M_{\text{de}} = \frac{\text{Count}(\text{“的”})}{N_{\text{chars}}}$$
  同时检测 15 字以内连续出现 3 个及以上「的」的严重定语堆积实例。

### 3.4 语域与排版癖好层（Register & Formatting Level）

#### 指标 3.4.1：Markdown 结构泛滥度（Formatting Obsession, $M_{\text{format}}$）
- **表现**：在明确的“即时聊天（Chat）”或“口头交流”任务中，模型依然强迫症式地输出 `### 标题`、`**加粗关键词**`、`- 无序列表`。
- **惩罚**：在 Chat 与纯文字口语场景中，按 Markdown 标记（`#`, `**`, `- `, `1. `）的出现密度线性扣分；在正式文档场景中则放行。

#### 指标 3.4.2：语气助词偏离度（Modal Particle Naturalness, $M_{\text{particles}}$）
- **定义**：统计中文常见自然语气词（`啊|呢|吧|嘛|哈|呀|哦|啦`）在非正式语域（Chat/Status）中的出现频次占句子数的比例。
- **双向锚定**：AI 常见病态为两种极端：（1）零语气词，全篇公文冰冷腔；（2）针对 prompt 矫枉过正，每句末尾机械加“哈”。必须落入 Pre-ChatGPT 人类基线分布区间 $[P_{25}, P_{75}]$ 才算正常。

#### 指标 3.4.3：破折号当万能连接号（Em-dash Abuse, $M_{\text{em\_dash}}$）
- **表现**：受英文 Em-dash 泛滥影响，中文模型极度喜欢用“——”来连接因果或转折，制造戏剧性悬念（例如：“结果终于出现了——文件彻底无法恢复——我们失去了所有记录”）。
- **公式**：统计中文破折号（`——`）在百字内的出现频率。

## 4. 打分体系与统计聚合模型（Scoring Pipeline & Aggregation）

### 4.1 四级聚合流水线
数据流处理严格遵循从微观到宏观的四级聚合：
1. **L1 单文本级（Instance Level）**：对单次生成的输出文本 $x$，运行 12 项病灶检测算法，输出原始物理指标向量 $\mathbf{m}(x) \in \mathbb{R}^{12}$。
2. **L2 Prompt 级（Task Level）**：对同一 Prompt 的 $K=5$ 次采样，计算样本均值与跨样本特征（如首句众数占比 $M_{\text{opener}}$），形成该 Prompt 的指标得分。
3. **L3 语域级（Register Level）**：在各语域（Chat, Status, Docs, Public）内部，将指标聚合为 5 大维度得分 $\mathbf{D}_d = [S_C, S_T, S_R, S_K, S_O]$。
4. **L4 模型级（Model Level）**：按预设权重合成为最终机械总分 $S_{\text{mechanical}}$，并与人类 Arena 分数混合。

```
[原始输出文本 x] ---> (12项微观指标提取器) ---> [实例向量 m(x)]
                                                     |
                                                     v (跨5次采样聚合: 开场白众数等)
                                              [Task级特征向量]
                                                     |
                                                     v (对照人类基线 P05/P95 归一化)
                                              [五大维度得分: C, T, R, K, O]
                                                     |
                                                     v (按语域与维度加权 25:25:15:20:15)
                                              [机械分 S_mechanical (60%)]
                                                     |
                                                     v + [人类盲测 Elo 转换分 (40%)]
                                              [总榜 Slop Index (0-100)]
```

---

### 4.2 基于人类基线的双分位数稳健归一化
绝不采用人为拍脑袋的阈值扣分，所有原始指标必须映射至 Pre-ChatGPT 人类真实分布。

针对单侧递增指标（数值越大越 slop，如黑话密度、套话密度、二元对比）：
设人类基线在同语域下的第 5 分位数为 $P_{05}$，第 95 分位数为 $P_{95}$。
$$\text{Score}(x) = 100 \times \min\left(1.0, \max\left(0.0, \frac{x - P_{05}}{P_{95} - P_{05}}\right)\right)$$
- 若模型表现优于或等于人类中最优秀的 5%（$x \le P_{05}$），得分归零（无 AI 味）；
- 若模型表现超过人类最差的 5%（$x \ge P_{95}$），直接拉满 100 分。

---

### 4.3 双侧偏离度惩罚算法（Two-sided Deviation Penalty）
对于具有双向合理区间的指标（如句长变异系数 $CV$、语气词密度 $R_{\text{modal}}$）：
设人类基线的中位数为 $M$，四分位距为 $\text{IQR} = P_{75} - P_{25}$。定义正常人类容忍区间为 $[P_{25} - 0.5 \times \text{IQR}, P_{75} + 0.5 \times \text{IQR}]$。
若 $x$ 落在该区间内，惩罚分 $S(x) = 0$；若落在此区间外，惩罚分按偏离边界的归一化距离计算：

$$S_{\text{two\_sided}}(x) = 100 \times \min\left(1.0, \frac{\text{dist}(x, [B_{\text{low}}, B_{\text{high}}])}{\text{IQR}}\right)$$

**设计价值**：彻底断绝模型通过 Prompt 注入指令（如“请你尽量多用语气词”或“严格使用短句”）进行单向指标刷分的可能性。

---

### 4.4 篇幅膨胀度单侧渐进惩罚公式（DIM-C）
借鉴 SlopBench 公式并校准为中文字符级统计：
设评测任务 prompt 严格设定的期望字数上限为 $U_s$（单位：有效汉字字符数，不计空白符）。
对于模型输出样本 $x$，其实际有效字数为 $L(x)$。定义单个样本的膨胀率 $c(x)$：

$$c(x) = \max\left(0, \frac{L(x) - U_s}{U_s}\right)$$

维度得分取该模型在所有评测样本集合 $X$ 上的均值，并进行非线性平滑放大：

$$S_{\text{DIM-C}} = 100 \times \min\left(1.0, \frac{1}{|X|} \sum_{x \in X} c(x)\right)$$

*工程特性*：
1. **单侧宽容**：字数在上限以内完全不扣分（允许言简意赅）；
2. **尾部敏感**：由于先求均值再做截断，少数“严重超长（2000字回复200字要求）”的极端输出会大幅拉高整体 slop 分，严厉打击模型的自说自话与过度发挥。

---

### 4.5 人类偏好盲测 Arena 与 Bradley-Terry/Elo 融合（40% 权重）
机械分无法 100% 覆盖人类复杂的情感共鸣与交流审美，因此设立「说人话 Arena」双盲众包对战平台：

1. **对战协议**：对同一 Prompt，随机抽取两个匿名模型的生成结果（A 与 B），在网页端打乱左右呈现给真实人类评审。
2. **评审准则**：“哪一个回答更像一个真实的、靠谱的真人给你的回复？（而不是机器味套话）”。
3. **Elo 评分与归一化**：
   采用标准 Bradley-Terry 逻辑斯蒂模型更新胜率，基础分设定为 1500。
   将模型的最终 Elo 分数 $R_m$ 映射至 $[0, 100]$ 的 Slop 偏好分：
   $$S_{\text{human}}(m) = 100 \times \left(1.0 - \frac{1}{1 + 10^{(R_{\text{human\_baseline}} - R_m) / 400}}\right)$$
   若模型对战人类基线文本胜率为 50%，则 $S_{\text{human}} = 50$ 分；胜率越高，AI 味判定越低。

---

### 4.6 统计检验、聚类 Bootstrap 与排名置信区间
为了防止榜单因随机采样产生虚假排名波动，本基准强制要求报告 **95% 置信区间**：
- **Prompt 聚类重采样（Cluster Bootstrap）**：以任务 Prompt 为聚类单元（保持 Prompt 内部 5 次采样的相关性），进行 $B = 1000$ 次有放回重抽样。
- **并列判定（Tie Groups）**：若两个模型的 Bootstrap 分布重叠概率超过 5%（即置信区间重叠且双样本检验 $p > 0.05$），在榜单中标记为同级并列（Tied），不强行区分先后。

- 任务 Prompt 中均明确注明字数约束区间（例如：“请控制在 100–150 字以内”）。
- **中文计字规则**：采用严格的 Unicode CJK 统一表意文字字符集匹配（`[\u4e00-\u9fa5]`），标点符号计入字符，连续空白符不计入。绝不使用易受分词器影响的 BPE Token 计数。

### 6.3 采样超参数与稳定性复现协议
- **Temperature**：统一固定为 $T = 0.7$；
- **Top-p**：$0.95$；
- **Max Generation Tokens**：$2048$；
- **随机种子与独立无状态**：每个任务进行 5 次独立 API 调用，无历史会话状态，每次调用传入不同的系统随机数种子，记录完整原始 logprobs（若模型开放）。

## 7. 防刷分与误杀保护机制（Anti-Gaming & Guardrails）

### 7.1 三级误杀豁免白名单（False-Positive Guards）

为确保评测具备工业级可靠性，避免将专业严肃的表达污名化，设立三级自动化过滤流水线：

```
输入文本 ──> [Filter-1: 代码块与引用隔离] ──> 仅分析散文正文
                │
                v
         [Filter-2: 专业术语白名单匹配] ──> 放行技术/法律专属词
                │
                v
         [Filter-3: 语法依存树事实核查] ──> 放行事实性排他二元对比
                │
                v
         进入 12 项病灶检测打分
```

1. **结构隔离**：Markdown 中的行内代码（`` `...` ``）、代码块（` ```...``` `）、表格、YAML Frontmatter 及 `>` 引用块一律不纳入套话指标统计。
2. **术语豁免**：建立包含 1,500+ 个计算机、金融、法律固定术语的白名单（如：“闭环控制系统”、“收敛条件”、“粒度控制”、“幂等重试”）。当此类词汇出现在匹配的技术主语或代码上下文中时，豁免扣分。
3. **真实排他性豁免**：对于包含客观逻辑反驳的句子（如“不是网络中断，而是鉴权失败”），依存句法分析确认其属于事实排他后，豁免二元对比惩罚。

### 7.2 对抗性 Prompt 破解与“伪口语化”防御
模型厂商在知晓 Benchmark 规则后，可能通过 System Prompt 进行对抗性刷分：
- **作弊手段 1：故意极简（截断文字）** $\to$ **防御**：任务 Prompt 设定字数带下限，低于下限 30% 触发“回答残缺惩罚”，直接判 0 分有效性。
- **作弊手段 2：机械堆砌口语词（刷口语活性）** $\to$ **防御**：语气助词与口语词采用双侧偏离度惩罚，超出人类正常使用上限（$P_{75} + 0.5 \times \text{IQR}$）同样重罚。
- **作弊手段 3：伪造错别字与口头禅** $\to$ **防御**：采用困惑度（PPL）与双盲人类 Arena 检验，机械造作的假口语在人类盲测中将遭遇断崖式低分。

### 7.3 题库分仓与动态防作弊机制
- **80 题公开集（Public Suite）**：供开发者本地调试、优化模型与复现算法。
- **40 题私有盲测集（Private Held-Out Suite）**：不公开 Prompt，官方评测在私有集上运行，定期轮换，彻底杜绝针对 Prompt 的过拟合与硬编码调优。

```python
RE_SYCOPHANCY = re.compile(r"(?:好问题！|很高兴为您|希望(?:以上)?(?:解答|内容)?能?对您有所帮助|欢迎随时向我提问)")
RE_ELEVATION = re.compile(r"(?:让我们(?:一起|共同)?(?:见证|期待|拥抱|书写)|未来已来|开启全新篇章)")
RE_MODAL_PARTICLES = re.compile(r"[啊呢吧嘛哈呀哦啦]")

def split_chinese_sentences(text: str) -> List[str]:
    # 剥离代码块
    clean = re.sub(r"```[\s\S]*?```", "", text)
    clean = re.sub(r"`[^`\n]+`", "", clean)
    sents = re.split(r"[。！？\n；;!?]+", clean)
    return [s.strip() for s in sents if len(s.strip()) > 0]

def compute_instance_metrics(text: str, upper_limit: int, register: str) -> Dict[str, float]:
    """计算单个生成文本的原始物理特征指标"""
    sents = split_chinese_sentences(text)
    n_sents = max(1, len(sents))
    chars = re.findall(r"[\u4e00-\u9fa5]", text)
    n_chars = max(1, len(chars))
    
    # 1. 篇幅膨胀度 (DIM-C)
    inflation = max(0.0, (n_chars - upper_limit) / upper_limit) if upper_limit > 0 else 0.0
    
    # 2. 句长变异系数 (DIM-R)
    sent_lens = [len(re.findall(r"[\u4e00-\u9fa5]", s)) for s in sents]
    mean_len = sum(sent_lens) / n_sents
    variance = sum((l - mean_len) ** 2 for l in sent_lens) / n_sents
    std_len = math.sqrt(variance)
    cv_len = std_len / mean_len if mean_len > 0 else 0.0
    
    # 3. 词汇与套话指标 (DIM-K)
    light_verb_cnt = len(RE_LIGHT_VERB.findall(text))
    binary_cnt = len(RE_BINARY.findall(text))
    four_char_cnt = len(RE_FOUR_CHARS.findall(text))
    sycophancy_cnt = len(RE_SYCOPHANCY.findall(text))
    elevation_hit = 1.0 if RE_ELEVATION.search(text) else 0.0
    
    # 4. 口语活性 (DIM-O)
    particles_cnt = len(RE_MODAL_PARTICLES.findall(text))
    particle_density = particles_cnt / n_sents
    
    return {
        "n_chars": n_chars,
        "inflation": inflation,
        "cv_len": cv_len,
        "light_verb_rate": light_verb_cnt / n_sents,
        "binary_rate": binary_cnt / n_sents,
        "four_char_density": (four_char_cnt * 100) / n_chars,
        "sycophancy": float(sycophancy_cnt),
        "elevation": elevation_hit,
        "particle_density": particle_density
    }

def normalize_feature(val: float, p05: float, p95: float) -> float:
    """单侧指标分位数截断归一化至 [0, 100]"""
    if p95 <= p05:
        return 0.0
    norm = (val - p05) / (p95 - p05)
    return 100.0 * min(1.0, max(0.0, norm))

def normalize_two_sided(val: float, p25: float, p75: float) -> float:
    """双侧指标偏离度惩罚归一化至 [0, 100]"""
    iqr = max(1e-5, p75 - p25)
    b_low = p25 - 0.5 * iqr
    b_high = p75 + 0.5 * iqr
    if b_low <= val <= b_high:
        return 0.0
    dist = (b_low - val) if val < b_low else (val - b_high)
    return 100.0 * min(1.0, dist / iqr)
```
